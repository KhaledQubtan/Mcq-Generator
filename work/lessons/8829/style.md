# Style profile (تمارين 10)
- Source: textbook-style exercises (mostly long word problems with several requested quantities) + 9 MCQs at the end (exam questions, "دور أول/ثانٍ").
- Forms: calculation of acceleration, tension, pressure on pulley ($\sqrt{2}$ ش), speed/distance after cutting the string, finding an unknown mass or friction coefficient from given data; two-pulley systems (body between two hanging masses); two bodies on table + one hanging; scale pan (كفة ميزان) hanging; MCQs with symbolic answers (e.g. $\frac{ك_2}{ك_1}$ for uniform velocity).
- Units: grams/dyne/cm (د = 980 سم/ث²) and kg/N/m (د = 9.8 م/ث²); answers often in ث.جم or ث.كجم; pressure as number $\times \sqrt{2}$.
- Stem length: medium-long (2-4 lines) for calculation, short for MCQs.
- Distractors in MCQs: near values from common mistakes (ignoring friction, using wrong mass in denominator, forgetting $\sqrt{2}$, unit confusion), fractions like 1/4, 1/3, 2/3, 1/2.
- Difficulty: mostly application (تطبيق) with some higher-level multi-step (مستويات عليا).
