# Style profile (تمارين 14 على طاقة الحركة)
- Forms: mostly "complete the statement" with a numeric blank (".... جول") followed by 4 numeric choices; some "ماعدا" (except) questions on units; ratio/percentage questions (نسبة بين طاقتي حركة، النسبة المئوية للفقد)؛ multi-part essay problems (collisions, fall and rebound, inclined plane) that can be split into single-answer MCQs.
- Stem length: 1-3 lines, data given with units, sometimes in mixed units (طن، كم/س، جم، سم/ث) requiring conversion.
- Distractors: wrong unit conversion (forgetting 5/18, using جم as كجم, جول vs ث.كجم.متر by 9.8, كيلو وات.ساعة factor 3.6 x 10^6), forgetting the 1/2, forgetting squaring, sign of change (positive vs negative), loss vs change, swapped ratio (4:25 vs 25:4, 2:5 vs 5:2), using momentum ratio instead of energy ratio.
- Difficulty mix: ~25% recall/concept (definition, units, properties), ~50% direct application, ~25% multi-step (collisions, fall/rebound, inclined plane, vectors, functions of time).
