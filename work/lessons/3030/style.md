# Style profile (أسئلة الوحدة 2 درس 6 - حركة جسم على مستوٍ خشن)
- Mostly calculation problems (≈85%): find م_ك, the force, acceleration, speed, distance, time, number of wagons, resistance per ton; unit mixing (جم/سم/داين, ث.كجم, ث.طن, نيوتن, كم/س).
- MCQ section ("اختر الإجابة الصحيحة") uses: symbolic formula choice (ج = د(جا θ - م_ك جتا θ)), comparison of times (ن1 < ن2), ratio questions (م_س : م_ك = 5:4; ح at ن=1 : ح at ن=3), reverse problems (find θ, find الوزن).
- Stems are medium-long (2-4 lines) giving full data; answers are single values with units.
- Distractors: forgetting د (using ث.كجم as نيوتن), using م_س instead of م_ك, sign error in sin/cos (adding instead of subtracting), forgetting the vertical component of an inclined force in ر, swapping sin/cos, wrong unit conversions (طن=1000 كجم، سم ↔ م), inverted ratios.
- Difficulty: ~25% recall/concept, ~45% standard application, ~30% multi-step.
