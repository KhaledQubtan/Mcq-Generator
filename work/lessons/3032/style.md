# Style profile (from OCR of the questions PDF; used only for form, not facts)

- Source: Google OCR text of "اسئلة الوحدة 3 درس 1" (digits often garbled; facts not trusted).
- Forms: mostly "اختر الإجابة الصحيحة" with an incomplete statement ending in "=" or "......" followed by a unit (direct numeric calculation, ~65%); conceptual recall ("الدفع هو"، "وحدة قياس الدفع"، "كل مما يأتي ... ما عدا"); compare/ratio questions (د1 ، د2، ع1 : ع2، زمن الإيقاف لكتلة مضاعفة); qualitative cause/effect (كرة المطاط والصلصال، رد فعل السقف أقل/أكبر من القوة الدفعية)؛ statement-choice questions ("أي الجمل الآتية يصف حركة المدفع").
- Stems: 1-3 lines, numeric data with mixed units (جم، كجم، طن، سم/ث، كم/س، داين، ث.كجم) so that unit conversion is part of the skill.
- Calculations: الدفع = ق ن، الدفع = ك(ع2 - ع1) with direction signs (ارتداد)، حفظ كمية الحركة (نفس الاتجاه/متضادين/التحام/سكون إحدى الكرتين/انشطار)، القوة الدفعية ورد الفعل (ق + و للأرض، ق - و للسقف، ق للحائط)، الدفع بالتكامل لقوة دالة في الزمن، الدفع المتجه (س، ص).
- Distractors: wrong unit conversion (factor 10^5، 9.8، 1000، 5/18)، ignoring direction (subtracting speeds instead of adding on rebound)، forgetting weight in reaction، swapping ratio، using sum instead of difference, near values.
- Difficulty mix: ~25% easy recall/one-step, ~50% medium (two steps with conversion/sign), ~25% hard (fall + rebound, integration, vector impulse, multi-step collisions).
- Choices: short numbers with or without unit; ordered ascending in the source for numeric choices.
