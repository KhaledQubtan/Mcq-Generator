# Plan (100 questions)
- c1 العجلة -> السرعة (18): ع من ح كثيرة حدود، إيجاد ع0 من شرط، ح ثابتة، تكامل مثلثي/أسي بسيط، مفاهيم (ح = دع/دن، المساحة تحت ح-ن). Examples: Q2, Q7, Q31-3/5, Q43.
- c2 السرعة -> الموضع/الإزاحة (22): س من ع مع س0، الإزاحة في فترة، الثانية النونية، اختيار الدالة الصحيحة، العودة لنقطة البدء، ح -> ع -> س. Examples: Q1, Q6, Q9, Q10, Q12, Q31-1/2, Ex8-14.
- c3 ح بدلالة س (16): ع^2 بدلالة س، س عند سرعة معطاة، أقصى سرعة مع هـ^-س، ح ثابتة ع^2 = ع0^2 + 2حف، ح بدلالة ع. Examples: Q13, Q14, Ex25-30.
- c4 الإزاحة/المسافة/تغير الاتجاه (22): المسافة مع تغير الاتجاه، السكون اللحظي، أقصى بعد، شرط أقصى سرعة (ح = 0)، أقصى ارتفاع (ع = 0)، جسمين. Examples: Q3, Q4, Q5, Q15, Q16, Q17, Q31-7/8/10, Ex13/15/38/39.
- c5 السرعة المتوسطة (10): متجه السرعة المتوسطة vs السرعة المتوسطة، العجلة المتوسطة. Examples: Q19, Ex16/17, Q40-5/6.
- c6 المنحنيات (12): منحنيات موصوفة بالكلمات (ح-ن خطي، ع-ن مثلثات/شبه منحرف، ح-س). Examples: Q11, Q18, Q20-23, Ex32, Q40-1/2.
Difficulty: ~30 easy, ~50 medium, ~20 hard. Forms: complete-the-statement numeric, choose the function, conceptual recall, which-is-false.
